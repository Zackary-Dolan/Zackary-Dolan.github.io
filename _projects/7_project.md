For my Book Factory project, I developed a Java-based application designed to manage book-related operations through an organised and structured system. The application uses object-oriented programming principles, including classes, objects, encapsulation and methods, to represent and manage different aspects of the system. Java allowed me to structure the application into separate components, making the code easier to maintain, reuse and expand.
